# light-2026.yazi

A Yazi flavor based on [dark-2026-theme/nvim](https://github.com/dark-2026-theme/nvim).

## Installation

```bash
# Via ya package manager
ya pkg add dark-2026-theme/yazi
```

Or manually clone this repository into your Yazi flavors directory:

```bash
git clone https://github.com/dark-2026-theme/yazi ~/.config/yazi/flavors/light-2026.yazi
```

## Usage

Set the content of your `theme.toml` to enable it as your light flavor:

```toml
[flavor]
light = "light-2026"
```

Make sure your `theme.toml` doesn't contain anything other than `[flavor]`, unless you want to override certain styles of this flavor.
